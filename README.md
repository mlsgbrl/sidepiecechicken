# Side Piece Chicken website

New site for the Side Piece Chicken food truck in Albany, GA. It's a single `index.html` file with no build step.

## Put it on GitHub (about 10 minutes)

1. Make a free account at github.com.
2. Click **New repository**, name it `sidepiecechicken`, set it to **Public**, and create it.
3. Click **Add file → Upload files**, drag in `index.html` and this `README.md`, then click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch", pick `main` and `/ (root)`, then **Save**.
5. After a minute the site is live at `https://YOUR-USERNAME.github.io/sidepiecechicken/`.

## Before going live

Everything in a yellow dashed box is a placeholder. Fill in with Pops:

- Phone number and email
- Weekly parking spots and hours
- Real menu, prices, and wing flavors
- Loyalty discount amount and catering minimum
- Facebook / Instagram links

- **Photos:** swap in real photos of the truck and food.
